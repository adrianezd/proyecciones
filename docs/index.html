Como esta montado

Cada pagina de arriba es su propio repositorio y su propio sitio de GitHub Pages, con su propia GitHub Action. No hay servidor: la Action lanza un script de Python cada doce horas, descarga la fuente correspondiente, calcula lo que haga falta y escribe HTML plano.

Como los datos ya vienen dentro del HTML, cada pagina carga al instante y no hace ninguna llamada externa cuando la abres.

Si una fuente esta caida cuando corre la construccion de una pagina, esa Action reutiliza el ultimo dato bueno guardado en cache. Nunca se rellena un hueco con datos aproximados o inventados.
